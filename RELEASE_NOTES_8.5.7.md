# BrickMissing 8.5.7 – Release Notes

- Geschlossene Minifigurenkarten sind kompakter. Das CSS-Grid zeigt je nach verfügbarer Breite mehr Karten nebeneinander.
- Geöffnete Karten überspannen auf größeren Bildschirmen mehrere Grid-Spalten. Ihre Bestandteile bleiben lesbar und bedienbar, während Nachbarkarten im Grid umfließen.
- Set-Minifiguren und einzeln hinzugefügte Minifiguren verwenden dasselbe Layout. Mehrere Karten können weiterhin gleichzeitig geöffnet bleiben.
- Die vorhandene Tastaturbedienung, Filter, Mengensteuerung und der Empty State bleiben erhalten.
- Keine Änderung an Datenmodell, Besitz, Mengen, Rebrickable, CSV, JSON oder Reconciliation. Keine Migration und keine neue Abhängigkeit.
